# Family portal in the staff look (owner-approved 2026-11-19)

Static boards from the design canvas, for builders to match:

- `Staff{Web,Phone}*.dc.html`: the 32 family portal pages in the staff portal's look (web-kit «Emerald Mint» tokens, Noto Sans Arabic, the staff sidebar on desktop, the family TabBar on phones), with the motion hooks in each board's style block.
- `FamRoom*`: the live session (join, device check, waiting, live, screen share, chat/participants, leave, left, ended), web + phone.
- `FamFiles*`: lesson files (lesson page, PDF, image, audio, empty, loading, error), web + phone.
- `FamChat*`: the family chat (entry, thread with every message kind, menu, info, attach, voice, offline, closed), web + phone.
- `FamRec*`: recordings (list, player, video, parts, from a report, expired, failed, empty, loading, offline), web + phone.

Open a board in a browser. Sample data is fake. The verified specs behind the feature boards are in `../family-features/`.
